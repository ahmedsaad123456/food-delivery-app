### Orders and Order Placement

- Create `Order` and `OrderItem` entities using the Aggregate Root pattern.
- Store order item snapshots (name and price) to preserve historical order data.
- Implement order creation and status transitions inside the `Order` entity.
- Define `OrderStatus` enum with allowed state transitions.
- Implement `DomainException` for invalid order state transitions.
- Implement `PlaceOrderCommand` and its handler to process order placement.
- Validate cart items against the menu and recalculate prices before creating orders.
- Save orders and clear the Redis cart within a single transaction.

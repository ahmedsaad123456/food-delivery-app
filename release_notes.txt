### Stripe Payment Integration
- Create a Stripe account in test mode and store the secret key in an environment variable (never hardcode it).
- Apply ISP + Adapter Pattern by creating three separate interfaces: CheckoutSessionCreator, PaymentRefund, and WebhookSignatureVerifier. Implement them in StripePaymentGateway to keep the domain independent of Stripe.
- Implement CreateCheckoutSessionCommand to create a checkout session from the Order using the order items' snapshots, include orderId in the session metadata, return the checkoutUrl, and use an Idempotency Key.
